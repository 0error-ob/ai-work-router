# 批量 JSON 抽取

**任务：** 从 200 条客服消息中抽取结构化字段，输出有效 JSON。

**任务类型：** 抽取、分类、结构化输出

## 任务结构画像

| 维度 | 取值 |
|---|---|
| Oracle 强度 | Medium-strong — schema 校验 + 人工抽样 |
| 视野长度 | 单步 |
| 歧义程度 | Low-medium — 部分消息可能有歧义 |
| 上下文依赖 | Low — 消息基本自包含 |
| 输出 | 结构化 JSON |
| 失败成本 | Low-medium |
| 可回滚性 | Easy |

## 路由策略

| 阶段 | 策略 |
|---|---|
| Plan | 普通模型或人工定义 schema |
| Execute | 廉价快速模型或结构化输出稳定型模型 |
| Verify | 先做 schema 校验；语义质量用人工抽样 |
| Repair | 重试无效 JSON；仅对歧义案例升级 |
| Package | 廉价模型 — 错误率摘要 + 歧义案例列表 |

## 升级触发条件

- 重试后仍有无效 JSON
- 分类定义有歧义
- 抽样审核分歧较大
- schema 在任务进行中发生变更

## 不可自动化条件

- 标签未定义
- 数据含敏感隐私信息且无保障措施
- 错误会触发不可撤销的客户操作
- 歧义案例无审核流程
